# comments_261010 데이터

comments_261010.csv는 2번csv.csv(101행)와 3번csv.csv(100행)를 이 순서로 합친 파일입니다.
201행·30컬럼의 모든 원본 값을 보존했고 UTF-8 BOM으로 저장했습니다. 원본 두 파일은 변경하지 않았습니다.

필수 열: translated_ko, label. GT: 0=부정, 1=긍정, 2=중립, 3=혼합, 4=판단 불가.
모두 학습 대상이며, 빈 라벨을 4로 변환하지 않습니다.
댓글 없는 메모 1행은 원본 파일에 보존하되 전처리에서 제외합니다.
학습 대상 200행의 라벨별 수는 0=57, 1=92, 2=37, 3=9, 4=5입니다.
숫자 label과 label_name이 다른 62행은 원본대로 유지했습니다. GT는 숫자 label만 사용합니다.
parent_id/comment_type과 작성자·그룹 ID는 답글 제외·분할에 사용하며 모델 특징에는 본문만 넣습니다.

선택 열과 전처리·그룹·분할 조건은 상위 README.md를 참고하세요.
수업용 synthetic_reviews.csv는 이 복사본에서 제거했고 원본 week06에는 유지했습니다.
